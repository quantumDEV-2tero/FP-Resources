# 📚 FP Library

> **A modern academic resource platform built for students, by students.**

FP Library is a student-focused digital platform designed to make academic resources easier to discover, organize, and share. It brings course materials, documents, community resources, and student tools together in one clean and responsive interface.

---

## ✨ Features

### 📖 Academic Resource Library
Browse and discover academic documents organized around courses and modules.

### 🔎 Smart Resource Discovery
Find useful academic materials quickly without searching through scattered files and messaging groups.

### 📤 Community Uploads
Students can contribute useful academic resources and help build a stronger shared library.

### 👥 Student Community
A platform designed around collaboration, resource sharing, and academic support.

### 🔐 Authentication
Secure Firebase authentication with:

- Google Sign In
- Email & Password
- Account Registration
- User Profiles
- Account Management

### 🌍 Multilingual Interface
Switch between:

- 🇬🇧 English
- 🇫🇷 Français
- 🇲🇦 العربية

### 🌓 Dark & Light Mode
Choose between dark and light themes for a comfortable experience.

### 📱 Fully Responsive
Designed for:

- 💻 Desktop
- 💻 Laptop
- 📱 Mobile
- 📟 Tablet

### 👤 Student Profiles
Authenticated users can create and manage their own profiles.

### 💬 Community Features
Authenticated users can access community-oriented features such as messaging, profiles, and shared resources.
